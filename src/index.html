    Stylescape with Vite

    This example demonstrates using Stylescape with Vite for fast development and optimized production builds.

    ⚡ Why Vite?

    • Lightning fast HMR (Hot Module Replacement)
    • Native ES modules support
    • Optimized production builds
    • Built-in Sass support

    Setup

    1. Install dependencies

    npm install stylescape
npm install -D vite sass

    2. Import in your Sass

    // src/scss/styles.scss
@use "stylescape";

    3. Import in your JavaScript

    // src/js/main.js
import "stylescape";

    4. Run development server

    npm run start

    What is Vite?

    Vite is a next-generation frontend build tool that offers a faster development experience.

    Does it support Sass?

    Yes! Just install sass as a dev dependency and Vite handles the rest.

    How fast is HMR?

    Vite's HMR is nearly instant, even in large projects, because it only updates what changed.
